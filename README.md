# 천하동시 (3KDmap)

요코야마 미츠테루 『전략 삼국지』 60권을 읽는 동무. 책을 펼친 그 시각, 중원·강동·서량과 한반도에서 동시에 일어나던 일을 전쟁상황실처럼 보여 줍니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000

- 시작: 책 스캔 또는 권 고르기
- 세계: 재생형 대시보드 (1초 ≈ 1일, 배속·스크럽)
- 내 위치: GPS 또는 도시 선택 → 동시대 한반도
- 목차: 60권. 1~10권 Plot 완성, 11~60권 스텁

## 원칙

- 만화 작화·대사는 쓰지 않음
- 본문은 연의 / 정사 / 자치통감 / 후한서 / 삼국사기 레이어
- 기본은 가족용 요약, 「본편 수위」에서만 잔혹 기록
- 기록이 없는 해의 한반도는 날조하지 않음
