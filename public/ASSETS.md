# 시각 자료 라이선스

요코야마 미츠테루 작화·대사·페이지는 일절 사용하지 않습니다.

| 파일 | 출처 | 라이선스 |
|---|---|---|
| `/portraits/*.jpg` | Grok Imagine 오리지널 생성 | generated — 이 앱용 재구성 |
| `/icon.svg` | 코드로 작성 | generated |
| 역사 지도 실루엣 | 경위도 폴리곤을 코드로 그림 | generated |

인물 초상은 특정 만화 디자인을 베끼지 않은 수묵풍 창작입니다.
장소·지도 라벨은 코드로 그려 글자가 틀리지 않게 했습니다.
